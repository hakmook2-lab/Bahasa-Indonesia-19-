# Belajar Yuk! (개인용)

인도네시아어 학습 웹앱 — 개인용 버전 (한국어 전용, 성인 섹션 포함)

## GitHub Pages 배포
1. GitHub에서 **New repository** → 이름 예: `belajar-yuk-private` → **Public** → Create
2. **Add file → Upload files** → 이 폴더 안의 파일 **전부**(Ctrl+A) 끌어다 놓기 → **Commit changes**
3. **Settings → Pages → Deploy from a branch → main / (root) → Save**
4. 1~2분 후 주소: `https://<아이디>.github.io/belajar-yuk-private/`

## 업데이트
같은 저장소에서 **Add file → Upload files** → 새 파일 전부 끌어다 놓기 → Commit (같은 이름은 덮어씀)
